# Latinas Design · vitrina web

Sitio de la tienda Latinas Design (Cochabamba). Publicado en Netlify: https://latinasdesing.netlify.app

- `index.html`: todo el sitio. Los productos están en la lista `PRODUCTOS` y las tiendas en `TIENDAS`.
- `assets/catalogo/`: fotos de las prendas, con el mismo nombre que el `slug` de cada producto.
- `assets/tiendas/`: fotos de las tres tiendas.

Cada cambio guardado en `main` se publica solo en Netlify.
